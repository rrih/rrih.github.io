プライバシーポリシー

更新日：2026年9月6日

基本方針

rrih が運営する Pokémon Atlas は、アカウント登録なしで利用できます。画像やシーンの保存は端末内で行い、アクセス解析は任意の同意に基づいて読み込みます。広告には Google AdSense を利用します。アクセス解析と広告に関する選択は別に扱います。

端末内に保存する情報

言語、表示設定、お気に入り、シーン、背景画像、プライバシー設定は、ブラウザの保存領域に保存します。背景画像には IndexedDB を使います。画像は表示用に変換し、必要に応じて縮小してから保存します。元のファイル名や画像のメタデータは保存しません。これらは表示の復元や、選択した機能を利用するための保存であり、運営者のサーバーへ自動送信するものではありません。

オフラインで閲覧できるよう、アプリやモデルなどの配信用ファイルも端末内に保存します。ブラウザや端末の設定からサイトデータを削除すると、これらの保存内容が消える場合があります。アプリの削除だけでは、ブラウザにデータが残る場合があります。

背景を表示から外しても、保存シーンで使えるよう端末内に画像が残る場合があります。端末内の背景画像をまとめて削除するには、ブラウザの設定でこのサイトのデータを削除してください。この操作では、保存シーン、お気に入り、設定も削除されます。すでにダウンロードした画像やシーンファイル、お使いの端末にある元の画像は、別途ご自身で削除してください。保存内容の自動同期や、運営者による復旧はできません。画像付きのシーンファイルを書き出すと、そのファイルに背景画像も含まれます。ファイルを他者へ渡す前に内容をご確認ください。

サイトの配信

このサイトは GitHub Pages から配信されます。ページやファイルを取得するとき、GitHub は IP アドレスやリクエスト情報などを処理します。アクセス解析を拒否しても、オンラインでサイトを配信するための通信は発生します。詳しくは GitHub のプライバシーに関する声明をご覧ください。

図鑑の出典リンク

図鑑の本文は、このサイトのファイルとして配信します。PokéAPIや日本語・中国語の公式図鑑など、出典欄の外部リンクを開くと、そのサイトとの通信が発生し、リンク先のプライバシーポリシーが適用されます。背景画像や保存シーンを出典サイトへ送信する機能はありません。

任意のアクセス解析

アクセス解析に同意した場合、Google Analytics を使い、利用状況を把握して表示や使い勝手を改善します。ページの閲覧回数、選択した表示言語、ブラウザや端末の情報、Cookie 等の識別子が処理される場合があります。計測用のページ情報にはアプリの固定のアドレスと名称を使い、検索文字、背景画像、画像の名前や識別子、シーン名を送信しません。Google シグナルと広告パーソナライズ用のシグナルは無効にしています。

Google による取り扱いは、Analytics のデータ保護情報と Google のプライバシーポリシーをご覧ください。

同意した範囲で、ページの表示速度、操作への応答時間、レイアウトのずれ、3Dモデルの読み込み時間と成否も集計します。ページ全体の速度指標は、訪問の開始時にアクセス解析への同意が保存されていた場合だけ収集します。訪問中に新しく同意した場合は、それ以降に開始したモデルの読み込みを対象とし、同意前の操作や読み込みをさかのぼって送信しません。モデルの識別番号やフォーム名は送信しません。

広告について

Google AdSense を通じて、小型で固定サイズの広告を最大1枠表示する場合があります。すべての地域で、過去の閲覧行動に基づいて選ばない非個人最適化広告を利用します。ただし、表示回数の制御、集計、不正防止などには Cookie 等を使用する場合があります。Google はページ情報、IP アドレス、ブラウザ・端末の情報、Cookie 等の識別子を処理する場合があります。詳しくはGoogle がパートナーのサイトで収集した情報を使用する仕組みをご覧ください。

広告に必要な選択を確認する間、広告のリクエストを一時停止した状態で Google の同意管理サービスを読み込みます。このため、広告について選択する前にも Google との通信が発生します。Google の広告リクエストの一時停止に関する説明では、この間も Google のドメインにある既存の Cookie が読み取られる場合がありますが、停止中の広告タグは新しい Cookie を設定せず、既存の Cookie に紐づく情報を広告配信や計測に使用しないとされています。

Google の欧州向け同意要件が適用される場合は、同意画面での選択が完了し、端末への情報の保存・アクセスと Google に対する同意がある場合に限り、広告をリクエストします。これらを拒否した場合、同意状態が不明な場合、同意管理サービスでエラーが起きた場合は、広告をリクエストしません。自動広告、全画面広告、追従広告は使用せず、ポケモンの切り替えや時間経過による広告の自動更新も行いません。

同意の選択と変更

アクセス解析は、同意する前には読み込みません。拒否しても閲覧やシーン作成の機能を利用できます。「プライバシー設定」から選択を変更し、同意を撤回できます。選択はこのブラウザに保存します。保存できない場合は、そのことを画面に表示し、現在の閲覧中だけ選択を適用します。

欧州向けの広告の選択が適用される場合は、アプリ下部の「広告のプライバシー設定」から広告への同意を確認・撤回できます。この設定を開くと、その後の広告リクエストを一時停止し、表示中の広告を取り除いて選択を待ちます。米国の州法に基づく選択が適用される場合は、「個人情報の販売・共有を拒否」から Google の同意管理サービスで選択できます。これらはアクセス解析用の「プライバシー設定」とは別の操作であり、一方に同意しても、もう一方に同意したことにはなりません。

アクセス解析への同意を撤回すると、新たな解析情報の送信を止めます。広告に必要な同意を撤回すると、その後の広告リクエストを止め、表示中の広告を取り除きます。ただし、選択を処理するために同意管理サービスとの通信が続く場合があります。撤回前に Google へ送信済みの情報が、その操作だけで削除されるわけではありません。端末の保存データや Cookie は、ブラウザの設定からも削除できます。

お問い合わせと情報に関する請求

GitHub Issuesにご自身で投稿した内容は、GitHub と運営者が受け取り、公開されます。投稿内容は問い合わせへの対応、不具合の修正や権利に関する確認のために使用します。公開する必要のない個人情報や機密情報は記載しないでください。

適用される法令に基づく情報の開示、訂正、削除、利用の制限などに関するご相談も、この窓口で受け付けます。本人確認に必要な情報を、公開の投稿に添付しないでください。運営者が受け取らない端末内だけのデータは、ご自身の端末で管理・削除できます。Google や GitHub が独自に保有する情報については、それぞれのプライバシー窓口も利用できます。

外部サービスと国外での処理

GitHub や Google は、サイトの配信、広告、同意管理、またはご自身が選択したアクセス解析のために、お住まいの国以外で情報を処理する場合があります。同意管理の通信は、アクセス解析や広告に同意した方に限って発生するものではありません。各社による保護措置、保存や削除の扱いは、上記のプライバシーに関する説明をご確認ください。背景画像を端末内に保存する操作とは、取り扱いが異なります。

このポリシーの変更

情報の扱いを変更する場合は、このページを更新します。新しい任意の用途で情報を扱う場合は、必要な説明と同意の手続きを行います。
