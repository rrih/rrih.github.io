このサービスについて

Pokémon Atlas は、ポケモンをさまざまな角度から眺めたり、複数のポケモンを並べたシーンを作ったりできる、rrih が運営する非公式のファン向けウェブアプリです。株式会社ポケモン、任天堂株式会社、株式会社クリーチャーズ、株式会社ゲームフリークおよびそれらの関連会社が運営、提供、承認するサービスではありません。

アカウント登録は必要ありません。表示できるモデル、フォーム、動作や機能は変更される場合があります。表示には独自の調整や近似が含まれるため、公式作品の見た目や設定を完全に再現するものではありません。

権利の帰属

ポケモンの名称、キャラクター、モデル、テクスチャ、イラストなどに関する著作権、商標権その他の権利は、各権利者に帰属します。Pokémon およびポケモンの名称は、任天堂、クリーチャーズ、ゲームフリークの商標です。

本アプリ独自のプログラムに適用されるオープンソースライセンスは、これらの素材の権利を含みません。素材の出典表示や本アプリで閲覧できることは、素材の再配布、販売、商用利用について許諾を与えるものではありません。素材の出典は権利・クレジット、プログラムの利用条件はライセンスをご覧ください。

図鑑の情報

図鑑の説明には、収録作品を記したゲームの図鑑文、公式図鑑を参照したAtlasの要約、基本データをもとにした説明があります。出典欄でこれらを区別し、情報源と確認日を示します。フォルムのページで標準種の説明を掲載する場合は、その旨を表示します。日本語・中国語の補完元を含む出典は、権利・クレジットをご覧ください。

ご自身の画像と保存したシーン

背景には、ご自身で使用する権利があり、他者の著作権、肖像権、プライバシーなどを侵害しない画像を選んでください。背景画像はお使いの端末内で処理・保存され、選択しただけで公開されたり、運営者へ送信されたりすることはありません。運営者が、その画像を広告や宣伝に利用する権利を取得することもありません。

画像やシーンのダウンロードは、第三者の権利を移転するものではありません。ダウンロードしたファイルを外部へ公開・送信するときは、含まれる画像やキャラクターに関する権利、写り込んだ人の同意、個人情報の有無をご確認ください。

シーン、お気に入り、背景画像などは、保存したブラウザや端末で利用するためのものです。端末間での自動同期は行いません。ブラウザのデータ削除、容量不足や端末の故障によって失われる場合があるため、必要なシーンは保存機能で書き出してください。画像付きのシーンファイルには背景画像も含まれ、ほかの端末へ渡すとその画像も渡ります。

利用上のお願い

違法な目的での利用、他者の権利侵害、不正アクセス、サービスの動作を妨げる行為は行わないでください。アクセス解析への同意は任意であり、同意しなくてもモデルの閲覧やシーン作成を利用できます。

広告とプライバシーの選択

小型で固定サイズの非個人最適化広告を最大1枠表示する場合があります。自動広告、全画面広告、追従広告は使用せず、ポケモンの切り替えや時間経過による広告の自動更新も行いません。広告の掲載は、運営者やポケモンの権利者が広告主の商品・サービスを推奨していることを意味しません。

広告とアクセス解析に関する選択は別に扱います。Google の同意管理サービス、情報の取り扱い、選択の変更方法については、プライバシーポリシーをご覧ください。

保守、不具合、配信元の変更、権利者からの申し出などにより、機能や素材を変更・削除したり、サービスを中断・終了したりする場合があります。可能な場合は、重要な変更をアプリ内でお知らせします。

運営者は、情報の正確性、すべての端末での動作、保存データの永続性を保証するものではありません。ただし、この規約は、適用される法令によって認められる利用者の権利を制限するものではなく、法令上免除できない責任を免除するものでもありません。

不具合、プライバシー、掲載素材の権利に関するご連絡は、運営者の GitHub Issuesへお寄せください。権利に関するご連絡では、対象のページやポケモン、問題となる素材、ご自身と権利者との関係を、公開可能な範囲でお知らせください。内容を確認し、必要に応じて掲載の見直しを行います。

GitHub Issues は公開されます。住所、電話番号、本人確認書類、非公開の契約書などは投稿しないでください。GitHub の利用には、同社の利用条件とプライバシーポリシーが適用されます。
